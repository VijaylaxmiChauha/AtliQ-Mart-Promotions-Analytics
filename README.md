AtliQ Mart – Promotions Analytics

Project Overview

This project focuses on analyzing promotional campaign performance for AtliQ Mart using SQL and Power BI.
The objective is to evaluate the effectiveness of different promotional campaigns, understand their impact on revenue and sales volume, and identify product and category-level performance.

Tools & Technologies

SQL – Data querying and analysis
Microsoft Power BI – Interactive dashboard development
Power Query – Data transformation
DAX – Measures and KPI calculations

Project Objectives

Analyze promotional campaign performance.
Evaluate incremental revenue generated through promotions.
Compare revenue before and after promotions.
Identify top and bottom-performing products.
Analyze product category performance.
Understand promotion effectiveness across stores and cities.
